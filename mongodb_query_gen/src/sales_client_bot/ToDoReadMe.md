#####  Agentic Design for the  Dynamic Search Query Filter

UserAgent → Accepts a search request in natural language.
QueryAgent → Converts it into a MongoDB-compatible query.
ValidationAgent → Checks for syntax errors in the generated query.
ExecutionAgent → Runs the query using the MongoDB driver.
ResponseAgent → Formats the query results and returns them.
